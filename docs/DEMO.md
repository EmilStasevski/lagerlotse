# Demo in drei Minuten

Wird gefüllt, sobald der MVP läuft. Ablauf:

1. (30 s) Problem: dieselben Fragen jede Woche, Zahlen aus mehreren Quellen.
2. (60 s) Chat: „Welche fünf Kunden hatten im letzten Quartal den höchsten Umsatz?", danach eine Folgefrage und eine Frage außerhalb des Umfangs.
3. (45 s) Prüfung: eine Antwort mit markierter Abweichung zeigen und erklären, warum sie nicht ungeprüft erscheint.
4. (30 s) Dashboard und Wochenbericht mit Nachbestellvorschlägen.
5. (15 s) Was als Nächstes käme: Rollen, ERP-Anbindung.
